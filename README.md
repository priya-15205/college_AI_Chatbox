# 🎓 AI-Powered College Information Chatbot

## 📌 Project Overview

The AI-Powered College Information Chatbot is a Python and Streamlit-based chatbot designed to provide quick and easy information about a college.

The chatbot allows students, parents, visitors, and other users to ask questions about college details such as courses, timings, CSE specializations, hostel, library, transportation, and available facilities.

The system uses Natural Language Processing techniques with TF-IDF and Cosine Similarity to understand user questions and provide relevant responses.
